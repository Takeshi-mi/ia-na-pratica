# Skills

Uma skill é uma receita escrita em texto que o agente segue passo a passo. Na palestra elas aparecem como exemplo do que dá para fazer: editar vídeo, gerar contrato, montar relatório.

As skills **não ficam neste repositório**. Elas são ferramentas que continuam sendo usadas e melhoradas depois do evento, então ficam num repositório próprio, com versão e instalação independentes. Este repositório só aponta para elas.

| Skill | O que faz | Onde está |
| --- | --- | --- |
| Fluxo de edição de vídeo | Prepara, corta, enquadra, legenda, mixa e renderiza vídeos gravados no celular | *(link do repositório de skills, quando for publicado)* |

Para instalar uma skill no Claude Code, coloque a pasta dela em `~/.claude/skills/` ou instale o plugin do repositório com `/plugin`.
